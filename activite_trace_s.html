Tracé d'une orbitale s : contour d'isovaleur

Plan (x, z) : section de la surface d'isovaleur ψ = cste
Coupe le long de l'axe z (x = 0) : ψ(z), avec r = |z|

Principe du tracé

ψ1s(r) = (ζ3/π)1/2 e−ζr
  1. On choisit une isovaleur ψ0 (ligne pointillée sur la coupe).
  2. On cherche les points où ψ(r) = ψ0 : comme ψ ne dépend que de r, la solution est un rayon unique r0 = ln(ψ(0)/ψ0) / ζ.
  3. L'ensemble des points à la distance r0 du noyau est une sphère ; sa trace dans le plan (x, z) est un cercle.
